# M&A 경영자문 Agent Workflow 확장 개발 계획

**프로젝트:** C-Level 경영지원 AI 멀티 에이전트  
**담당 분야:** 경영자문 Agent  

## 1. 개발 개요

본 개발은 C-Level 경영지원 AI 멀티 에이전트 프로젝트의 경영자문 Agent를 대상으로 기존 M&A 타당성 평가 Workflow를 확장하는 것을 목적으로 한다.

기존 데모의 LangGraph 기반 Agent 구조 및 M&A 평가 Tool을 재활용하며, 다양한 인수 조건을 반영한 시나리오 분석과 경영진 관점의 종합 평가 기능을 구현한다.

## 2. 개발 목표

1. 기존 M&A 평가 로직의 오류 및 기업별 조건 처리 개선
2. 인수가격 및 주요 위험 조건을 변경할 수 있는 시나리오 분석 기능 개발
3. 변경 전후의 재무적 위험과 인수 권고 비교 기능 개발
4. CEO·CFO·CTO Persona 기반 종합 평가 결과 제공
5. 결과의 판단 근거와 사용 데이터·가정값 명시
6. 기존 Agent 구조와의 호환성 유지 및 테스트 수행

## 3. 개발 범위

### 3.1 기존 평가 Workflow 개선

- 기업의 실제 영업이익률에 따른 수익성 판정
- 특허 분쟁 유무에 따른 위험 평가
- 기업별 재무적 위험 및 인수 조건 처리
- 기존 M&A 평가 기능에 대한 회귀 테스트

### 3.2 M&A What-if 시나리오 분석

- 인수가격 변경 시 프리미엄 재계산
- 주요 고객 의존도 변화 시 위험 재평가
- 수익성 변화 시나리오 적용
- 시나리오별 인수 권고 결과 산출
- 기본 조건과 변경 조건의 비교

### 3.3 경영자 Persona 종합 분석

- CEO: 전략 적합성 및 사업 가치
- CFO: 인수가격, 수익성, 재무 위험
- CTO: 기술 적합성, 핵심인력, 기술 위험
- Persona별 평가 결과와 공통 위험 요인 통합
- 최종 권고 및 선행 조건 정리

### 3.4 근거 및 검증 기능

- 평가에 사용한 기업 데이터와 가정값 명시
- 분석 기준 및 입력 조건 확인
- 테스트 케이스 작성 및 평가 결과 검증
- 기존 Super Agent와의 연동 확인

## 4. 기존 코드 활용 계획

| 파일 | 개발 내용 |
|---|---|
| `mna_review.py` | 평가 오류 수정 및 시나리오 입력 확장 |
| `run_mna_review.py` | Tool 입력·출력 인자 확장 |
| `mna_feasibility_review.py` | 추가된 Workflow 기능에 맞춰 호출 지침 수정 |
| `companies.json` | 필요한 기업 데이터 및 평가 조건 보완 |
| `test_mna_review_workflow.py` | 신규 테스트 케이스 작성 |

추가 모듈이 필요할 경우 기존 구조와의 호환성을 검토한 후 분리한다.

## 5. 개발 일정

### 1주 차: 기존 시스템 개선
- 기존 M&A Workflow 분석
- 수익성·특허 위험 등 평가 오류 수정
- 기존 테스트 및 추가 테스트 수행

### 2주 차: M&A 시나리오 확장
- 인수가격 변경 기능 구현
- 고객 의존도·수익성 변화 시나리오 적용
- 시나리오별 평가 및 결과 비교
- 입력값 검증 및 예외 처리

### 3주 차: 경영진 종합 평가 및 검증
- CEO·CFO·CTO 종합 분석
- 분석 결과 및 가정값 표시
- Agent Tool 연동 테스트
- 시연 시나리오 및 개발 결과 정리

## 6. 개발 제외 및 향후 확장 항목

이번 기간에는 아래 기능의 전면적인 신규 구현을 필수 범위로 설정하지 않는다.

- 다수의 실제 기업을 대상으로 한 DART 자동 수집 플랫폼
- 대규모 문서 수집 및 벡터 DB 기반 RAG 시스템
- 전문적인 기업가치평가 및 재무예측 모델
- 독립적인 CEO·CFO·CTO Agent 세 개의 신규 구현
- 새로운 프론트엔드 전체 개발

해당 항목은 공통 인프라 및 다른 팀 개발 범위와 연계하여 향후 확장한다.

## 7. 완료 기준

- 기존 M&A Workflow의 주요 평가 오류 해결
- 인수가격 변경에 따른 계산 및 결과 비교 가능
- 최소 2종 이상의 위험 조건 변경 시나리오 지원
- CEO·CFO·CTO 관점의 종합 분석 제공
- 기존 기능과 신규 기능의 자동 테스트 통과
- 기존 경영자문 Agent 및 Super Agent 호출 흐름에서 실행 검증

## 8. 최종 기대 결과

기존 고정 데이터 기반 M&A 검토 데모를 다양한 인수 조건과 경영자 관점을 반영할 수 있는 의사결정 지원 Workflow로 확장한다.

이를 통해 경영진은 인수 조건 변화에 따른 재무·전략·기술 위험과 권고 결과를 비교하고, 주요 판단 근거를 확인할 수 있다.
